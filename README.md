# 📚 cheecode_Y1S1

Welcome to my Year 1 Semester 1 (Y1S1) academic repository! 

This repository serves as a personal archive and a helpful reference guide containing all my coursework, notes, and code from my first semester. 

## 🗂️ Subjects Covered

This repository contains materials for the following courses:

* **WIA1007** - Introduction to Data Science
* **WIX1001** - Computing Mathematics
* **WIX1002** - Fundamentals of Programming
* **WIX1003** - Computer Systems and Organization

## 📂 What's Inside?

Inside the folders for each subject, you will generally find the following resources:
* **📖 Notes:** Personal study notes, summaries, and revision materials.
* **📝 Tutorials:** Solutions and attempts for weekly tutorial questions.
* **💻 Labs:** Source code and submissions for practical lab sessions.
* **📚 Past Year Questions (PYQ):** Practice attempts for past exam papers.
* **🚀 Extra Exercises:** Additional coding challenges and math exercises used for revision.
