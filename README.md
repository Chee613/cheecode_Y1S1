# 📚 cheecode_Y1S1

This repository serves as a personal archive and reference guide containing all coursework, lecture notes, lab exercises, tutorial solutions, and revision materials from my first semester in Computer Science.

## 📂 What's Inside?

Across each subject directory, you will find:

* **📖 Notes & Slides:** Official lecture slides, course proformas, and concept study notes.
* **📝 Tutorials:** Questions and step-by-step solutions for weekly tutorials.
* **💻 Labs:** Practical programming exercises, Java source files, and Jupyter notebooks.
* **📚 Past Year Papers (PYQ):** Midterm and final exam practice papers.
* **🚀 Extra Exercises:** Comprehensive MCQ question banks, scenario analysis, and calculation challenges.
